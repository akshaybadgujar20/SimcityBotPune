# Setup and Running

[← Back to index](README.md)

## Prerequisites

| Requirement | Purpose |
|-------------|---------|
| **Python 3** with venv | Run the bot and dependencies |
| **Android emulator** | SimCity BuildIt host (BlueStacks, LDPlayer, Android Studio AVD, etc.) |
| **ADB** on PATH | Device connection and shell input |
| **Tesseract OCR** | Read building names and quantities |
| **SimCity BuildIt** | Installed and logged in on the emulator |

### Emulator resolution

Automation uses **fixed screen coordinates** in [`city_utility_actions.py`](../simcity/bot/automation/city_utility_actions.py) and several city actions. Templates and coords are tuned for a specific resolution. If detection fails after setup, verify emulator resolution matches what the templates were captured for.

### Tesseract path

[`main.py`](../simcity/bot/main.py) sets a Windows default:

```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```

On Linux or macOS, install Tesseract via your package manager and update this path, or set the `TESSDATA_PREFIX` environment variable as needed.

## Install

From the project root:

```bash
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
```

### Dependencies

From [`requirements.txt`](../requirements.txt):

- `Flask`, `flask-cors` — API server
- `numpy`, `opencv-python` — image processing
- `pytesseract` — OCR wrapper
- `uiautomator2` — gesture automation

Optional for `trade_bot` YAML config: `pip install pyyaml`

## Connect the emulator

1. Enable ADB debugging on the emulator (usually enabled by default on desktop emulators).
2. Note the emulator's ADB port (common defaults: `5555`, `5554`, `5605`).
3. Connect manually if needed:

```bash
adb connect 127.0.0.1:5555
adb devices
```

[`set_up(device_id)`](../simcity/bot/main.py) runs `check_adb_devices_and_connect_if_not_connected` on every API action — it will attempt `adb connect 127.0.0.1:{device_id}` if the port is not listed.

## Run the Flask API server

```bash
python simcity/bot/server.py
```

- Binds to `127.0.0.1:5000`
- `debug=False`

Trigger actions via `POST /action-perform` — see [API](api.md) for examples.

Stop a running action:

```bash
curl -X POST http://127.0.0.1:5000/action-stop \
  -H "Content-Type: application/json" \
  -d "{\"port\": \"5555\"}"
```

## Multi-city setup

Run **one emulator per ADB port**. Each port gets its own action thread and stop event in the Flask server.

Example:

| City / emulator | ADB port | API `port` field |
|---------------|----------|------------------|
| City A | 5555 | `"5555"` |
| City B | 5605 | `"5605"` |

`trade_bot` supports concurrent cities by passing distinct `device_id` values — timers and capture folders are scoped per device.

## Logging

- **File:** `simcity_buildit.log` in the **current working directory** (overwritten each `set_up()` call)
- **Console:** INFO level, same format
- Format: `DD-MM-YYYY - HH:MM:SS - filename:line - LEVEL - message`

Run the server from a consistent working directory (project root recommended) so log and `data.json` paths are predictable.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| `device_id is NOT present in adb devices` | Emulator not running or wrong port | Start emulator; `adb connect 127.0.0.1:{port}` |
| Template matches always empty | Wrong resolution or outdated templates | Match emulator resolution; recapture templates |
| OCR returns garbage | Tesseract not installed or wrong path | Install Tesseract; update path in `main.py` |
| Action does not stop | Handler ignores `stop_event` | See [city-actions](city-actions.md) stop behavior table; `buy_items` does not check stop |
| `ImportError: check_if_trade_depot_open` | Missing function in `trade_depot.py` | Do not use `collect_sold_item_money` / `advertise_all_items_on_trade_depot` until fixed |
| Server returns `unknown action` | Typo in `action` string | Use exact enum names from [API dispatch table](api.md#action-dispatch) |
